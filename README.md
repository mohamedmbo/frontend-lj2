# Pokémon Team Manager

React-app voor het bekijken van Pokémon, het bewaren van favorieten en het beheren van teams.

## Starten

```bash
npm install
npm run dev
```

## Functionaliteit

- Pokémon ophalen via de PokéAPI
- zoeken en filteren op favorieten
- dynamische detailpagina per Pokémon
- teams aanmaken en verwijderen
- Pokémon toevoegen aan en verwijderen uit teams
- herbruikbare React-componenten en routing met `react-router-dom`

De wireframes staan in de map `docs/wireframes` en in `docs/Pokemon-Team-Manager-Wireframes.docx`.
